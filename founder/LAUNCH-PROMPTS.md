## P1: Segment mode: one audience, complete data

```
Use the fullstack-dev-skills:typescript-pro and fullstack-dev-skills:postgres-pro skills.

CollegeStat covers 14,000+ universities but data depth is uneven (e.g. 7 scholarships, 20 dates). We are
focusing on <SEGMENT>.
1. Write scripts/segment/coverage.ts: for a list of target universities (data/segment/targets.json, which I will
   fill; start it with the 200 universities this segment applies to most, chosen from our own catalogue by
   destination country + ranking, and mark it DRAFT for my review), report per university which fields are
   present, sourced and current-cycle: tuition (with currency/year), living cost, admission requirements,
   English test minimums, application deadline, application fee, scholarships, official links.
2. Output outputs/segment-coverage.md: a table sorted by completeness, plus the 30 most impactful missing fields.
3. Do not invent or fill data. Only report gaps.
Checks: script runs; numbers match a manual spot check of 3 universities.
```

Then fill the gaps over a few sessions, using the existing ingestion pipeline (`docs/LOCAL-DATA-PIPELINE.md`), with sources only.

## P2: The paid product: Shortlist Report

```
Use the fullstack-dev-skills:fullstack-guardian, fullstack-dev-skills:react-expert and meta-skills:modern-web-design skills.

Build the one thing we will charge for: a personal University Shortlist Report for <SEGMENT>.
1. Intake form (reuse lib/student-intake.ts and the student profile): scores (IELTS/SAT/GPA), budget per year in
   USD, subject, preferred countries, need for scholarship.
2. Matching (reuse lib/admission-sim.ts, lib/calculator.ts, scholarship data): 12-15 universities split into
   Reach / Match / Safe, each with tuition + living cost (with year and currency), requirements vs the student's
   scores, next deadline, scholarships they qualify for, and the official links. Every figure keeps its source;
   unknown stays "unknown", never zero (existing project rule).
3. Report page /report/<id> plus PDF export with a clean print layout and a month-by-month timeline to the
   deadlines.
4. Free preview: 3 universities visible, the rest blurred with "To'liq hisobot" (unlock). Unlock is a flag on the
   report row; payments come in P4.
5. Only universities with complete data (P1 coverage) may appear in a report.
Checks: typecheck/lint/test/build pass; a report for a sample profile shows only sourced figures.
```
