## Architecture inspected

The application uses React 19, TypeScript, Vinext/Vite and Supabase/PostgreSQL. `app/` contains routes, API entry points and styles; `pages-ui/` holds page views; `components/college/` supplies product/account UI; `lib/` holds domain and discovery rules; `server/` assembles public data and authenticates bounded server operations; `services/` handles workspace, admin and optional AI clients. The reviewable source library is in `data/published/`; reproducible ingestion and SQL preparation are in `scripts/ingestion/` and `scripts/database/`. Raw caches and generated exports stay ignored. The migrations, proposals, source receipts, data manifests and operations/checkpoint documentation were inspected without remote mutations.
