# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Email security@collegestat.xyz (placeholder: confirm before publishing) with steps to reproduce. We aim to reply within 3 working days and to fix confirmed issues within 30 days. We credit reporters who want it.

## Scope

In scope: this repository's code and scripts (for example, injection through data files, unsafe file handling, leaked secrets in history).

Out of scope: the live website's infrastructure testing, social engineering, denial of service. Do not access other users' data.

## Secrets

This repo must never contain keys or personal data. If you find any, report it privately so we can rotate it.

## Data accuracy

Wrong university data is not a security issue. Use the data correction issue template.
