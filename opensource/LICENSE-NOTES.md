# Licence files to add when publishing

- `LICENSE` (root): Apache-2.0 text for code under `scripts/` and `.github/`.
- `DATA-LICENSE.md` (root): CC BY 4.0 for everything under `data/`, with attribution line: "Data: CollegeStat contributors, https://collegestat.xyz, CC BY 4.0".
- `NOTICE`: lists third-party sources: IPEDS/College Scorecard (US public domain), Wikidata (CC0), Hipo university list (MIT, include `HIPO-LICENSE.txt`).
- Replace placeholders `OWNER_NAME`, `security@collegestat.xyz`, `conduct@collegestat.xyz` once decided.
